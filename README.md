# 🌾 KRUSHI CONNECT — "First Serve Farmers"

> **ONE WEBSITE → MULTIPLE AGRICULTURAL APPLICATIONS → ONE CONNECTED ECOSYSTEM**

**Krushi Connect** is a production-quality, modern, full-stack agricultural technology ecosystem designed as a central agricultural operating system. Inside Krushi Connect, 7 dedicated, interactive agricultural mini-applications operate seamlessly:

1. **Land Leasing Platform**: Connect uncultivated agricultural land with active farmers, interactive land profile cards, property maps, multi-step lease proposals, and contract agreements.
2. **Labour Community**: Agricultural workforce marketplace with worker skill profiles, daily rates, job posting engine, worker applications, and hiring workflows.
3. **Crop Demand Prediction AI**: Market intelligence dashboard featuring crop demand scores (Tomato 91%, Onion 84%), Recharts trend analytics, and an interactive Soil & Location AI crop recommendation engine.
4. **Crop Market & Storage**: Direct produce marketplace for fruits, vegetables, and grains, "Sell Produce" listing generator, and a cold storage/warehouse locator with distance and pricing.
5. **₹1 Scheme & Insurance**: Educational and guidance center for Pradhan Mantri Fasal Bima Yojana (₹1 crop insurance token enrollment) and instant eligibility checker.
6. **Precision Farming Command Center**: Satellite-style interactive farm map, automated N-P-K soil gauges, micro-climate weather forecasts, and drip irrigation scheduler.
7. **Cultivation Monitoring**: Active farm tracker, interactive 6-stage crop growth timeline, task checklist manager (create, complete, delete), and automated pest alert center.

---

## Ecosystem Features

- **Global Navigation & Mega-Menu**: Instant switching between central launchpad and sub-application modules with dedicated sidebars.
- **Multi-Role Perspective Switcher**: Test the system as a **Farmer**, **Landowner**, **Agricultural Worker**, **Produce Buyer**, or **System Administrator**.
- **Internal Direct Messaging**: Integrated live chat connecting Farmers, Landowners, Workers, and Buyers.
- **Global Notification Center**: Real-time notifications for lease proposals, job applications, market price surges, and weather warnings.
- **3D Hero Visualizer**: Interactive Three.js / Canvas agricultural landscape with satellite node, field plots, and camera controls.
- **Admin Governance Console**: Platform analytics, user registry, content moderation tools, and system health status.

## Getting Started Quickly

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
npm run start
```
